# Shop Saldo — roteiro de melhorias

## Prompt de execução

> Modernizar a landing page Shop Saldo sem perder o logo original, a identidade preto/laranja, o endereço e os contatos existentes. Eliminar conteúdo repetido, melhorar legibilidade e aproveitamento da tela em computador, tablet e celular, dar feedback visual sutil aos departamentos e reforçar o caminho para consulta pelo WhatsApp. Respeitar `prefers-reduced-motion`. Não criar preços, fotos ou descontos fictícios: uma vitrine de ofertas com itens reais deve ser alimentada pela loja.

## Sequência

1. Revisar estrutura e preservar os links oficiais já configurados.
2. Remover chips repetidos do hero e limpar a mensagem de apresentação.
3. Refinar os cartões de departamentos, tornando mais clara a ação para consultar itens.
4. Ajustar os espaçamentos responsivos, estados de foco e efeitos de hover.
5. Compilar, checar TypeScript e conferir o GitHub Pages após publicar.

## Pendente de conteúdo da loja

Fotos reais, nomes dos produtos, valores, estoque e condições promocionais. Só então criar uma vitrine de ofertas com preços.
